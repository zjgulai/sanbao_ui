## 接线深度分级（wire_depth_target）

| 值 | 含义 |
|---|---|
| `read` | 壳读真事实驱动渲染（如 readKnowledge/readCapabilities） |
| `write` | 动作走壳（提交/停止/回答等） |
| `read+write` | 两者（会话链等） |
| `entry` | 入口/跳转：导航到已接线页；自身无独立事实，验证入口存活 |
| `read/honest` | 有壳读得到就读，读不到/不适用→如实标注未接线（统一诚实面） |
| `n/a` | 纯证据/研究态（ResearchDetail 文档；不注入壳 UI） |

## 架构决策（并行安全的接缝用法）

- **容器页直连接缝**：knowledge/sites/extensions/settings 等容器页面在自己组件内 `getHostPort()`＋挂载读（效果与 cancelled 清理），**不经过 app.tsx**——多 worktree 并行时各批互不改同一文件。
- **跨页会话态走 app**（已存在）：sessionRef/binding/轮询（P01+S1+S2 已接线）。
- **host.ts 只允许加法**：新族在自己的 worktree 里给 `SanbaoHostPort` 追加可选方法（`readXxx?`），git 可自动合并；不许改动已接线方法的语义。
- **fixture 不动**：任何新 surface 只在 `hostReady`/`hostPort` 分支出现；无壳分支保持原 DOM/文案（fixture 控制组判红即回退）。
